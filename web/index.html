Overview

One project, from raw images to an explained prediction

Everything needed to download data, train, evaluate, predict and demo a classifier lives in one folder of plain Python scripts.

Classify

Four-way classification into glioma, meningioma, pituitary and no tumor. A binary report folds those into tumor vs. no tumor and gives sensitivity and specificity, the numbers that matter most for a screening-style question.

Explain

Grad-CAM is implemented from scratch with no extra package. Each prediction comes with a heat-map of the image regions that pushed the network toward its answer.

Use

Train with one command, predict on a file or a folder from the command line, or open the Gradio web app, upload an image and read class probabilities next to the heat-map.

The dataset

Brain Tumor MRI Dataset by Masoud Nickparvar on Kaggle. About 7,000 images (roughly 5,700 for training and 1,300 for testing), around 150 MB, combining public collections from figshare, SARTAJ and Br35H. Check its license on the Kaggle page before using it beyond personal learning or research.

Training pipeline

Warm up the head, fine-tune everything, test once

The recipe runs in a fixed order, so the numbered steps below are the real sequence train.py follows.

  1. Load and preprocessConvert each slice to three channels, resize to 224×224, normalise with ImageNet statistics.
  2. Augment training images onlyHorizontal flip, rotation up to 10°, 5% shift, 0.95–1.05 zoom, brightness and contrast jitter of 0.2.
  3. Hold out validation data15% of Training/ becomes the validation set. Testing/ is never used to choose a model.
  4. Warm-upWith a pre-trained backbone frozen, only the new classification head trains for --freeze_epochs epochs.
  5. Fine-tuneEverything unfreezes. AdamW with cosine learning-rate decay, class-weighted cross-entropy, label smoothing, gradient clipping, mixed precision on NVIDIA GPUs.
  6. Keep the best checkpointSaved whenever validation macro-F1 improves. Training stops early after --patience epochs without improvement.
  7. Evaluate once on the test setThe best checkpoint is scored a single time and writes metrics, plots and a list of every misclassified image.

Architectures

Four models behind one flag

Pick a network with --model. The three torchvision models start from ImageNet weights and get a new dropout and linear head for four classes.

Explainability

What the network looked at, and what that does not mean

Grad-CAM (Selvaraju et al., ICCV 2017) is implemented in gradcam.py. Try the viewer at the top of the page to see the overlay it produces.

  1. Hook the last convolutional stagelayer4[-1] for ResNets, features[-1] for EfficientNet-B0 and the small CNN.
  2. Backpropagate the chosen class scoreCapture the activations A and the gradients for the predicted class.
  3. Weight each channelAverage the gradients over the spatial grid to get one weight per channel.
  4. Combine and rectifyWeighted sum of channels, then ReLU, scaled so its peak equals 1.
  5. Upsample and blendBilinear resize to the input size, jet colours, 0.45 blend over the image.
L = ReLU( Σk αk · Ak ),  αk = meanx,y ∂yc/∂Ak
Reasonable behaviour

Attention lands on or near the abnormal region inside the brain, and moves when the lesion moves.

Warning sign

Attention sits on the skull edge, the background or a scanner marking. The model may be using a shortcut instead of the tumor.

Not a segmentation

The map is coarse. A 7×7 grid stretched over the image cannot outline a tumor, and it must not be read as its exact location.

Always shows a hot spot

Because the map is scaled to its own peak, some region lights up red even for a no-tumor image. Check the class probabilities, not only the colours.

Quickstart

From zip file to web app in five commands

Needs Python 3.9 or newer (3.10 to 3.12 recommended). On an NVIDIA GPU, install the CUDA build of PyTorch from pytorch.org first.

1. Set up

Create a virtual environment and install the packages.

cd brain_tumor_detection
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

2. Get the data

Automatic download needs a free Kaggle account. Or download the zip manually and move Training and Testing into data/.

pip install kagglehub
python download_dataset.py
python dataset.py --data_dir data     # counts per class, checks every image opens

3. Train

Also runs the single test evaluation at the end. Results land in outputs/.

python train.py --data_dir data
python train.py --data_dir data --model efficientnet_b0 --epochs 25

4. Predict

One image or a whole folder. Prints probabilities and saves an input and Grad-CAM figure.

python predict.py --image path/to/mri.jpg
python predict.py --image path/to/folder --save_dir outputs/predictions
python predict.py --image path/to/mri.jpg --no_cam

5. Website and analyser

Opens at 127.0.0.1:8000 with the page you are reading and the working Try-it box. app.py is a simpler Gradio alternative on port 7860.

python web_app.py
python web_app.py --port 8080
python app.py          # optional Gradio version

Optional: smoke test

Trains on cartoon images for a minute or two to prove the install works. The results mean nothing medically.

python tools/make_synthetic_data.py --out synthetic_data
python train.py --data_dir synthetic_data --output_dir outputs_test \
  --model resnet18 --no_pretrained --epochs 3 --batch_size 16 --num_workers 0

Hardware and time

With ResNet-18 on about 5,700 images, a recent NVIDIA GPU takes well under a minute per epoch. A laptop CPU takes several minutes per epoch, so budget roughly an hour for 10 to 15 epochs. With no GPU, use a free Google Colab or Kaggle Notebook with a GPU runtime and download outputs/best_model.pt afterwards.

Troubleshooting

FileNotFoundError: Data directory ...

The dataset is not in data/. Follow step 2, then run python dataset.py --data_dir data.

Kaggle download fails or asks for a login

Create an API token at kaggle.com/settings and put kaggle.json in ~/.kaggle/, or set KAGGLE_USERNAME and KAGGLE_KEY. You can also download the dataset by hand.

Could not load pre-trained weights

There is no internet for the ImageNet download. Connect and retry. Otherwise training starts from random weights and accuracy will be lower.

Windows errors mentioning multiprocessing or workers

Add --num_workers 0.

CUDA out of memory

Use --batch_size 16 or 8, or switch to resnet18.

Checkpoint not found

Run train.py first. The default path is outputs/best_model.pt.

Port 7860 is already in use

Run python app.py --port 7861.

Limitations and responsible use

What a good score on a public dataset does not tell you

No real-world accuracy is claimed

The project was code-tested end to end on synthetic images: training, evaluation, Grad-CAM, prediction, the web app and all four architectures. It was not trained on the real dataset where it was written. ImageNet-pretrained CNNs commonly reach high accuracy on this kind of task, but your numbers will vary with model, seed and epochs.

Public data has blind spots

Scans from other hospitals, scanners, protocols or patient groups can behave very differently. Public datasets can hold duplicates and near-duplicates, and the labels are not clinically re-verified here.

Read the whole report

Trust the per-class table, the confusion matrix and the missed-tumor count more than one accuracy figure. Glioma vs. meningioma is a common confusion.

Ideas to improve it

  • Train longer with efficientnet_b0 or resnet50, or try --img_size 256 or 300.
  • Use k-fold cross-validation and an ensemble of models.
  • Check the dataset for duplicate images across train and test.
  • Evaluate on an external dataset from a different source.
  • Add calibration such as temperature scaling so confidence values are more trustworthy.
  • Move to 3D, multi-sequence MRI models for clinical-style work.
FAQ

Frequently asked questions

Short answers to what people ask first. Still stuck? Send a note through the feedback form below.

Can I use this to diagnose a tumor?

No. It is an educational and research project, not a medical device. Never use it to diagnose, rule out or make decisions about any medical condition. Always rely on a qualified radiologist or physician.

How accurate is it?

No trained results ship with the project, so there is no accuracy figure to quote. ImageNet-pretrained CNNs commonly score high on this kind of dataset, but your numbers will vary with model, seed and epochs. After training, read the per-class report, the confusion matrix and the missed-tumor count, not one accuracy number.

Which dataset does it use?

The Brain Tumor MRI Dataset by Masoud Nickparvar on Kaggle, about 7,000 images in four classes. Check its license and terms on Kaggle before using it beyond personal learning or research.

Do I need a GPU?

No, but training on a CPU is slow. Budget roughly an hour for 10 to 15 ResNet-18 epochs on a laptop. A free Google Colab or Kaggle Notebook with a GPU runtime finishes an epoch in well under a minute on a recent NVIDIA card.

Which model should I start with?

resnet18. It is the default, light and fast. Try efficientnet_b0 or resnet50 once the pipeline works, and simple_cnn if you want a from-scratch comparison.

What does the heat-map actually show?

The image regions that influenced the model's decision. It is not a tumor outline or location. It is also scaled to its own peak, so some area looks hot even on a no-tumor image. If it highlights the skull edge or background, the model may be using a shortcut.

Can I train on my own dataset?

Yes. Any folder with one sub-folder per class works. Without Training/ and Testing/ folders the code makes a stratified 70/15/15 split. The tumor vs. no-tumor report only appears when a class is named notumor.

Why is the model picked on validation macro-F1?

Macro-F1 averages the score of every class equally, so a rare class is not hidden by a common one. The test set is never used for model selection. The best checkpoint is scored on it exactly once.

Is it safe to upload real patient scans to the web app?

The app runs on your own machine by default. Do not use --share with patient images, because it creates a temporary public link. Follow the privacy and medical-data rules that apply to you.

Will I get the same results every time?

Random seeds are set (default 42), which keeps runs close to repeatable. GPU operations and different hardware can still cause small differences.

What license is the project under?

The code is provided for learning and research with no warranty. The dataset has its own license on Kaggle, and you are responsible for following it.
